# demo-git

#Cel projektu
Nauka pracy w programie Git Hub
## Wymagania
- Python 3.11+
 
## Instalacja
```bash
git clone https://github.com/uzytkownik/projekt.git
cd projekt
pip install -r requirements.txt
```
 
## Użycie
```bash
python main.py --input dane.csv
```
 
## Struktura
- `data/` - dane wejściowe
- `notebooks/` - analizy
- `src/` - kod źródłowy
